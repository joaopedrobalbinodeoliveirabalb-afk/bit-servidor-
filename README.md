# Veletti — servidor

Servidor inicial do projeto Veletti, feito com Node.js e Express.

## Como iniciar

1. Instale o Node.js.
2. No terminal, execute `npm install`.
3. Copie `.env.example` para `.env` (opcional).
4. Execute `npm start`.

O servidor usa a porta 3000 por padrão.

## Rotas iniciais

- `GET /` — mensagem de funcionamento.
- `GET /health` — verificação de saúde do servidor.
